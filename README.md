# ReminderBot
A Telegram bot for creating reminders in C#


## Bot version 1.1

Бот сохраняет текстовые заметки, есть возможность установить разную частоту, тип и время для напоминаний напоминаний. 
Все напоминания сохраняются в базу данных на основе SQLite.

Рабоет:
/create
/delete
/all
/timezone
