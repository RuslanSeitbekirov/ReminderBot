# ReminderBot
A Telegram bot for creating reminders in C#




## Bot version 1.2
Проблемы verson 1.1:
- Напоминания нумируются для всех пользователей ✅Решено
- В базу данных незаписываются новые пользователи (таблица обновляется после закрытия программы) ✅Решено

Рабоет:
- /create
- /delete
- /all
- /timezone
- /edit_note

Изменения:
    1. В названии и тексте напоминания можно использовать символы
    2. Добавлен счёткик до срабатывания
    3. Временные метки для раннего срабатывания
    4. Отключение напоминания

Неработает:
- Кнопка назад в меню /edit_note
- Одноразовые напоминания как тип


## Bot version 1.1

Бот сохраняет текстовые заметки, есть возможность установить разную частоту, тип и время для напоминаний напоминаний. 
Все напоминания сохраняются в базу данных на основе SQLite.

Рабоет:
/create
/delete
/all
/timezone

Не работает:
/edit

Проблемы:
- Напоминания нумируются для всех пользователей
- В базу данных незаписываются новые пользователи (таблица обновляется после закрытия программы)
